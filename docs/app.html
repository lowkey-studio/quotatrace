Where did my quota go? Analyse your logs in the browser

Pick the folder Codex or Claude Code keeps its logs in. The files are read inside this page and nothing is uploaded: you can turn off your network after the page loads and it still works.

Analyse your logs

Nothing leaves this page
Codex
the sessions folder inside .codex in your home folder: ~/.codex/sessions on Mac and Linux, C:\Users\<you>\.codex\sessions on Windows.
Claude Code
the projects folder inside .claude (~/.claude/projects).

Hidden folders: on Mac press Cmd+Shift+. in the picker; on Windows type the path into the picker's address bar.

Prefer a terminal? npx github:lowkey-studio/quotatrace. Want to see the output first? Read a sample report made from synthetic logs.

The report holds counts only: session ids are one-way hashes, with no prompts, paths, file names or outputs. This page uses a cookie-free GoatCounter counter that records page views and the fact that an analysis ran, never anything from your logs (public counter).
