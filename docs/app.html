Where did my quota go? Analyse your logs in the browser

Pick the folder Codex or Claude Code keeps its logs in. The files are read inside this page; nothing is uploaded (you can turn off your network after the page loads and it still works). Prefer a terminal? npx github:lowkey-studio/quotatrace

Codex: the sessions folder inside .codex in your home folder: ~/.codex/sessions on Mac/Linux, C:\Users\<you>\.codex\sessions on Windows.
Claude Code: the projects folder inside .claude (~/.claude/projects).
Hidden folders: on Mac press Cmd+Shift+. in the picker; on Windows type the path into the picker's address bar.
